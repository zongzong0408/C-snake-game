# 貪食蛇小遊戲 v1

基於 **C 語言** 開發的基礎控制台小遊戲。
實現單執行緒同步遊戲迴圈。

---

## 🛠 系統架構

### 1. 數據結構
* **`MAP[HEIGHT][WIDTH]`**: 存放在 **資料區段** 的全域二維陣列，充當渲染緩衝區與碰撞偵測圖。
* **`snakeX[]`, `snakeY[]`**: 儲存在 **堆疊 (Stack)** 中的一維陣列，用以記錄蛇身每一節的座標順序，長度限制為 100。

### 2. 位移覆蓋
1.  從尾巴 `snakeLen - 1` 開始，將每一節的座標賦值為其前一節 `i - 1` 的座標。
2.  更新蛇頭 `snakeX[0]` 的座標。
3.  同步更新地圖 `MAP`：抹除舊尾巴、標記新頭部。

---

## 🚀 編譯與執行 (Compile & Run)

### 環境需求
```text
OS: Windows
```

### 編譯指令
```bash
gcc snake.c -o snake.exe
```

### 操作說明

* **w**: 向上移動
* **s**: 向下移動
* **a**: 向左移動
* **d**: 向右移動
* **q**: 退出遊戲

---

## 📝 開發筆記

1. **阻塞式輸入**: 目前採用 `scanf`，移動前需按下 Enter，屬於同步 I/O。
2. **畫面刷新**: 使用 `system("cls")` 暴力清空緩衝區，在低速 CPU 下可能會有輕微閃爍。
3. **邊界判定**: 透過 `MAP[y][x] == 3` (牆壁) 進行即時碰撞檢查。
